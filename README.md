## 📁 Panduan Deploy ke Hosting Rumahweb (cPanel)
1. Unduh repositori ini via tombol **Code** -> **Download ZIP**.
2. Buka cPanel Rumahweb -> **File Manager** -> folder `public_html`.
3. Upload seluruh file:
   - `index.html`
   - `favicon.ico`
   - `favicon.png`
   - `logo.png`
   - `logo-square.png`
4. Cukup gunakan paket hosting **Entry (Rp15.000/bln)** karena website ini tidak memerlukan database MySQL/Node backend.
